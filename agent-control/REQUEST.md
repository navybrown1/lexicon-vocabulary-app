# REQUEST

Build a modern interactive English words learning app.

## Goal

Create a polished front-end app that helps users learn English vocabulary through interactive word cards, examples, categories, and quiz mode.

## Required Features

1. Modern landing/header section.
2. Vocabulary learning cards.
3. Each word should include:
   - word
   - meaning
   - example sentence
   - category
   - difficulty level
   - pronunciation hint if practical
4. Interactive next/shuffle word behavior.
5. Quiz mode with multiple-choice answers.
6. Instant feedback after answer selection.
7. Score tracking.
8. Progress indicator.
9. Category filter or search if practical.
10. Responsive design for desktop and mobile.
11. Strong modern UI:
    - gradients
    - soft cards
    - clean typography
    - subtle animations
    - hover states
    - polished spacing
12. App should run locally without paid APIs or credentials.
